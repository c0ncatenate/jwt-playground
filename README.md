# JWT Playground

An interactive FastAPI app for learning how JSON Web Tokens (JWTs) are issued, validated,
and broken – safely, in a controlled lab.

## Scenarios

- **Scenario 1 – Signed JWT flow**: issue a signed JWT for a user and inspect its header and payload.
- **Scenario 2 – Tampering with claims**: coming soon.
- **Scenario 3 – Expired tokens**: coming soon.
- **Scenario 4 – Bad practices (training only)**: coming soon.

## Running locally

```bash
./scripts/run.sh
```

Then open http://localhost:8000/ in your browser.

This project is for educational use only. Do not reuse these secrets or patterns in production.
